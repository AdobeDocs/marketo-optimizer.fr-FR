# Création de contenu - suivi des liens

Le panneau de suivi des liens fournit une vue centralisée où vous pouvez facilement localiser chaque URL dans le contenu. Cliquez sur l’icône _[!UICONTROL Liens]_ ( ![Afficher l’icône des liens](../user-guide/assets/do-not-localize/icon-links.svg) ) à gauche pour afficher toutes les URL liées dans votre contenu. Il s’agit des liens dans les composants texte, bouton ou image.

Pour définir le tracking d’un lien de contenu répertorié, cliquez sur l’icône _Modifier_ ( ![icône Modifier](../user-guide/assets/do-not-localize/icon-edit.svg) ) et modifiez le **[!UICONTROL Type de tracking]** ou **[!UICONTROL Libellé]**.
