# Page d’accueil

Utilisez la page [!UICONTROL Accueil] dans [!DNL Adobe Marketo Optimizer] pour démarrer des conversations sur l’IA, lancer des compétences et ouvrir des espaces de travail marketing. Sélectionnez **[!UICONTROL Accueil]** dans la barre de navigation pour revenir à cette page.

Le message de bienvenue personnalisé vous interroge sur vos tâches actuelles. Choisissez comment commencer avec l’entrée de conversation, les options d’intention, les cartes d’accès rapide ou les cartes de compétences.

Regardez la vidéo pour découvrir la page d’accueil et l’espace de travail marketing. Les sections suivantes fournissent des instructions écrites.

>[!VIDEO](https://video.tv.adobe.com/v/3505360/?quality=12&learn=on)

## Démarrer une conversation d’IA

Utilisez l’entrée [!UICONTROL  Poser une question ou démarrer une tâche ] pour commencer à travailler avec [!UICONTROL Collègue]. Saisissez les `/` pour parcourir les compétences et les commandes.

1. Saisissez une question ou décrivez la tâche que vous souhaitez effectuer.
1. Pour fournir des pièces justificatives, sélectionnez **[!UICONTROL Joindre]** dans l’entrée et joignez un fichier.
1. Envoyez votre invite pour continuer dans le panneau [!UICONTROL Collègue].

La page d’accueil propose également quatre options d’intention pour commencer votre travail.

| Option | Objectif |
| -------- | ------ |
| [!UICONTROL Planifier] | Planifiez les activités marketing. |
| [!UICONTROL Create] | Créer du contenu ou des ressources marketing. |
| [!UICONTROL Mesure] | Examinez les performances marketing. |
| [!UICONTROL Optimisation] | Affinez les activités marketing existantes. |

Pour plus d’informations, consultez l’[interface de chat](/help/user-guide/agents/chat-interface.md).

## Accès rapide

Sélectionnez une carte [!UICONTROL Accès rapide] pour ouvrir un espace de travail ou consulter l’intégrité de la prise de décision de l’IA.

| Carte | Éléments auxquels vous pouvez accéder |
| ------ | --------------------- |
| [Santé de la prise de décision par l’IA](/help/user-guide/agents/ai-decisioning-health.md) | Volume des histoires et pourcentage de personnes classées par persona. |
| [Marketing ](/help/user-guide/marketing/marketing-management.md) | Programmes, parcours de personnes et listes de personnes dans l’espace de travail marketing. |
| [!UICONTROL Assets] | Ressources de contenu pour les e-mails et les pages |
| [!UICONTROL Rapports ] | Rapports de performance et d’engagement. |

## Compétences

Sélectionnez une carte dans [!UICONTROL Compétences] pour démarrer un workflow d’IA spécifique.

| Compétence | Objectif |
| ------- | ------ |
| [!UICONTROL Création d’audiences basées sur les rôles] | Générer des audiences à l’aide de signaux personnels et d’un ajustement firmographique. |
| [!UICONTROL Créer des programmes omnicanal] | Composez des programmes sur des e-mails, des sites web et des destinations à partir d’un résumé. |
| [!UICONTROL Créer des e-mails hyper-personnalisés] | Créer des brouillons d’e-mails personnalisés avec des jetons et des blocs de contenu dynamique. |
| [!UICONTROL Contrôle du trafic du parcours basé sur l’adaptation et l’intention] | Acheminez les contacts entre les parcours à l’aide de signaux d’adaptation et d’intention de compte. |

Vous pouvez également parcourir les compétences d’agent à partir de [!UICONTROL Coworker]. La vidéo présente la boîte de dialogue [!UICONTROL Utiliser une compétence d’agent] avec un champ de recherche et des filtres de catégorie. Pour plus d’informations, consultez la section sur les [compétences des agents](/help/user-guide/agents/skills.md).

## Accéder aux espaces de travail

Utilisez la navigation de l’application pour ouvrir les zones de travail suivantes à partir de la page d’accueil ou de l’espace de travail marketing.

| Espace de travail | Éléments auxquels vous pouvez accéder |
| ----------- | --------------------- |
| [!UICONTROL Gestion marketing] | Programmes, parcours de personnes et listes de personnes. |
| [!UICONTROL Contrôle de trafic de Parcours ] | [Contrôle du trafic Parcours ](/help/user-guide/marketing/journey-traffic-control.md). |
| [!UICONTROL Rapports ] | Rapports de performance marketing. |
| [!UICONTROL Gestion de contenu] | [!UICONTROL Modèles], [!UICONTROL Assets], [!UICONTROL Fragments], [!UICONTROL Forms], [!UICONTROL Pages de destination] et [!UICONTROL Webinaire]. |
| [!UICONTROL Connexions] | [ Destinations ](/help/user-guide/audiences/destinations.md). |
| [!UICONTROL Labs] | [Scoring Studio](/help/user-guide/labs/scoring-studio.md). |
| [!UICONTROL Administration] | [!UICONTROL Canaux] et [!UICONTROL Types de programmes]. |

## Explorer l’espace de travail marketing

Sélectionnez la carte d’accès rapide **[!UICONTROL Marketing]** ou **[!UICONTROL Gestion marketing]** dans la navigation pour ouvrir l’espace de travail marketing. Travaillez avec [!UICONTROL collègue], ouvrez des ressources marketing et revenez aux éléments récemment consultés sans revenir à la page d’accueil.

1. Sélectionnez **[!UICONTROL Programmes]**, **[!UICONTROL parcours de personne]** ou **[!UICONTROL Listes de personnes]** dans le panneau **[!UICONTROL Marketing]** pour parcourir les ressources.
1. Sélectionnez une ressource pour l’ouvrir dans un onglet de l’espace de travail . Vous pouvez également sélectionner un élément dans **[!UICONTROL Accès récent]**.
1. Pour continuer à travailler avec différentes ressources, basculez entre les onglets ouverts.

Le panneau [!UICONTROL Collègue] reflète la ressource que vous ouvrez. Ses invites peuvent cibler un programme, une liste de personnes ou une personne sélectionnés. Par exemple, l’ouverture d’un enregistrement de personne fournit des invites pour explorer la personne et l’activité d’engagement de cette personne.

Sélectionnez **[!UICONTROL Réduire]** pour masquer le panneau [!UICONTROL Collègue] ou **[!UICONTROL Permuter]** pour modifier son emplacement. Pour plus d’informations, consultez les sections [Gestion marketing](/help/user-guide/marketing/marketing-management.md) et [Détails de la personne](/help/user-guide/audiences/person-details.md).
